# Security policy

microtunnel is pre-1.0 (alpha) and has not had an independent security audit.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub:
**Security → Report a vulnerability** on <https://github.com/jecklgamis/microtunnel/security/advisories/new>.

Do not open a public issue for security problems. Include the version, your
configuration (with secrets removed) and steps to reproduce. You'll get an
initial reply within a few days.

## Scope

The protocol and its limits are described in [docs/security.md](docs/security.md).
